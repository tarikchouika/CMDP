## ما هي منصة CMDP؟

نظام رقمي شامل لإدارة التعاونيات في المملكة المغربية: رقمنة التعاونية وأنشطتها وكل ما له علاقة
بها — الجهات الحكومية والإدارية الوصية، والقوانين واللوائح التنظيمية الجاري بها العمل
(القانون رقم 112.12 المتعلق بالتعاونيات والنصوص التطبيقية له).

### الوحدات

| الوحدة | الوصف |
| --- | --- |
| 📊 لوحة القيادة | مؤشرات فورية، رسوم بيانية، مواعيد نظامية قادمة |
| 🏛️ التعاونيات | سجل التعاونيات: التسجيل بالسجل المحلي، بطاقة الاعتراف ODCO، ومصادقة التسجيلات الجديدة |
| 👥 الأعضاء | المنخرطون، الحصص الاجتماعية، مناصب المجلس الإداري |
| ⚖️ الجمع العام والمجلس | الجمعات العامة ومحاضرها، اجتماعات مجلس الإدارة، حضور الأعضاء وتصويتهم |
| 💰 المالية والصندوق | المداخيل والمصاريف، الرسوم البيانية، تقارير قابلة للطباعة |
| 📄 سجل الوثائق | أرشيف زمني مع تنبيهات انتهاء الصلاحية ومشاركة الوثائق مع المتعاقدين |
| 🏢 الجهات الوصية | دليل الجهات (ODCO، الضرائب، CNSS...) وسجل التفاعلات معها |
| 📚 القوانين واللوائح | مكتبة الإطار القانوني + دليل مسار التأسيس |
| 🔐 المستخدمون والمصادقات | طلبات التسجيل والانخراط، الأدوار، إنشاء الحسابات وتفعيلها |
| 💼 فرص العمل والتعاقد | سوق عمومي: مناصب شاغرة، فرص تعاقد وشراكة، حاجات خدمية، تداريب + الترشح |
| 🧑‍🌾 فضاء العضو/المتعاقد | حقوق المنخرط: حضور الجموع العامة والتصويت (ق.112.12) واطلاع المتعاقد على المصرح به |
| 📜 المركز القانوني | الشروط العامة، الخصوصية (ق.09.08)، الإشعار القانوني (ق.53.05)، ملفات التعريف |
| 🤖 المساعد الألي | شاتبوت بلا هلوسة: روابط بيضاء حصرية وبديل محلي حتمي عند تعذر العامل |

### نظام الأدوار (1.1.0)

**سوبر أدمين** (مالك المنصة — كل الصلاحيات) ← **أدمن** (المصادقة على التعاونيات
وتعيين الكوأدمن والحسابات) ← **كوأدمن** (رئيس التعاونية — كل صلاحياتها وتفويض
المهام؛ أو عضو مسير) ← **مستخدم عادي** (عضو غير مسير بحضور وتصويت، أو متعاقد
يطلع على المصرح به فقط). الصلاحيات مفروضة في الواجهة **وعلى الخادم** بمصفوفة
مشتركة (`src/lib/permissions.ts`).

### البنية المعمارية

```
┌─────────────────────────┐         ┌──────────────────────────────┐
│   الفرونت إند (ساكن)    │   ───▶  │   الباك إند المحلي (Next.js) │
│   Cloudflare Pages      │  HTTP   │   API Routes + Prisma        │
│   cmdp.pages.dev        │  CORS   │   قاعدة SQLite محلية         │
└─────────────────────────┘         └──────────────────────────────┘
        │
        │ HTTPS
        ▼
┌────────────────────────────────────────────┐
│   المساعد الألي — Cloudflare Workers AI    │
│   حساب مستقل · cmdp-assistant.             │
│   tkchouika-cmdp.workers.dev               │
└────────────────────────────────────────────┘
```

- **وضع كامل (محلي/سيرفر):** تطبيق Next.js واحد يقدم الواجهة وواجهات REST API مع قاعدة SQLite
  ومصادقة برموز موقعة (HMAC) وصلاحيات مفروضة على الخادم.
- **وضع العرض (ساكن):** نسخة تصدر ساكنة تعمل ببيانات نموذجية مدمجة، ويمكن ربطها بالباك إند
  المحلي في أي وقت من **الإعدادات ← الاتصال بالباك إند المحلي** (تُخزَّن في متصفحك).
- **المساعد الألي:** عامل Workers AI على حساب Cloudflare مستقل — بلا هلوسة (روابط بيضاء
  حصرية) مع بديل محلي حتمي داخل الواجهة عند تعذره.

## التشغيل السريع (الباك إند الكامل)

```bash
# 1) التثبيت
npm install        # أو: bun install

# 2) قاعدة البيانات (SQLite محلية)
cp .env.example .env
npm run db:push    # إنشاء الجداول

# 3) البيانات النموذجية (9 تعاونيات، 90 عضواً، 146 حركة مالية، 10 فرص...)
npm run seed       # أو: bun run seed

# 4) التشغيل
npm run dev        # http://localhost:3000
```

**حسابات الدخول التجريبية** (كلمة المرور الموحدة `cmdp2026`):
`superadmin` (المالك) · `admin` · `president` (رئيسة تعاونية) · `manager` (عضو مسير) ·
`member` (عضو غير مسير) · `contractor` (متعاقد)

## بناء النسخة الساكنة (للنشر على Cloudflare Pages)

```bash
npm run build:static   # المخرجات في out/
```

## حزمة التقنيات

- **Next.js 16** (App Router) + **TypeScript 5**
- **Tailwind CSS 4** + **shadcn/ui** (طابع مغربي: زليج، أقواس، درجات الطين والزعفران)
- **Prisma ORM** + **SQLite** (محلي)
- **TanStack Query** + **Zustand** + **Recharts**
- خطوط عربية: **Cairo** (عناوين) / **Tajawal** (نصوص) / **Amiri** (زخرفي)

## ملاحظة قانونية

المنشور بالجريدة الرسمية للمملكة المغربية. المصادر المعتمدة في التوثيق:
وزارة السياحة والصناعة التقليدية والاقتصاد الاجتماعي والتضامني (mtaess.gov.ma)
