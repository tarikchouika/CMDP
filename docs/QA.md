## 3) اختبارات وظيفية يدوية (سيناريوهات المسار الذهبي)

- [x] الدخول بالبيانات الصحيحة → لوحة القيادة ببيانات التعاونية النشطة
- [x] فشل الدخول → رسالة خطأ عربية واضحة
- [x] إضافة عضو جديد → يظهر في الجدول (تحقق كتابة قاعدة البيانات)
- [x] تبديل التعاونية النشطة من الشريط العلوي → تحديث المؤشرات
- [x] إنجاز التزام من المواعيد النظامية → تحديث الحالة فوراً
- [x] تصفية الوثائق حسب النوع + حساب آلي لحالة الصلاحية
- [x] فتح تقرير مالي للطباعة → جدول بترويسة وخانة توقيع
- [x] تصفية التفاعلات حسب الجهة (ODCO…)
- [x] توسيع النقاط الأساسية للقانون 112.12
- [x] وضع العرض التجريبي: تعطيل الكتابة مع رسالة إرشادية

## 4) مؤشرات قياس الجودة المستمرة

| المؤشر | الهدف | القياس |
| --- | --- | --- |
| زمن استجابة API المحلي | < 300ms للنقاط البسيطة | توقيت curl |
| حجم الحزمة الساكنة | < 5MB | du -sh out/ |
| أخطاء الكونسول | 0 عند التحميل والتنقل | agent-browser console |
| نسبة نجاح فحص الجودة في كل مهمة | 100% من البوابات G1–G7 | WORKLOG |
| تغطية الوحدات بالفحص البصري | كل وحدة في كل إصدار | لقطات موثقة |

## 5) إيقاع المراجعة

- **بعد كل مهمة:** G1–G4 ذاتياً.
- **قبل كل إصدار (دمج إلى main):** G1–G7 كاملة + سيناريوهات المسار الذهبي.
- **أسبوعياً (مساعد البيئة):** فحص صحة API + قاعدة البيانات + نسخة احتياطية محفوظة.
