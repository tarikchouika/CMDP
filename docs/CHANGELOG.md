## [1.1.0] — 2026-11-04

إصدار نظام الأدوار والانخراط والفرص — توسعة كبرى تحافظ على كل مكتسبات 1.0.x.

### أُضيف

- **نظام الأدوار والصلاحيات الرباعي**: سوبر أدمين (مالك المنصة — جميع الصلاحيات)،
  أدمن (المصادقة على تسجيل التعاونيات، إنشاء/المصادقة على الحسابات، تعيين الكوأدمن)،
  كوأدمن (رئيس التعاونية أو عضو مسير — تسيير التعاونية والمصادقة على الانخراطات
  وإنشاء الحسابات داخلها، والرئيس يفوّض المهام للمسيّرين)، ومستخدم عادي (عضو غير مسير
  أو متعاقد). التنقل والوحدات والقوائم كلها مفلترة حسب الدور في الواجهة **وعلى الخادم**.
- **المصادقة بالرموز الموقعة**: دخول يعيد رمز HMAC بصلاحية 7 أيام يُلحق بكل طلب،
  وحراسة صلاحيات ونطاق (الكوأدمن داخل تعاونيته حصراً) على كل مسارات الكتابة.
- **تسجيل الزوار**: واجهة «حساب جديد» بثلاثة مسارات: حساب مجرد، أو انخراط في تعاونية
  قائمة (يصادق عليه رئيسها أو أحد مسيّريها)، أو طلب تسجيل تعاونية جديدة (تصادق عليه
  إدارة المنصة ويُفعَّل حساب الرئيس). كل الطلبات بحالة PENDING حتى المصادقة.
- **وحدة المستخدمين والمصادقات**: طلبات معلقة (حسابات/انخراطات/تعاونيات) بأزرار
  مصادقة ورفض، إدارة الحسابات (أدوار، إيقاف، تصفير كلمة مرور)، وإنشاء حسابات مباشرة
  بالأدوار المتاحة لصلاحية الموظِّف. المصادقة على الانخراط تُنشئ سجل العضوية تلقائياً.
- **سوق فرص العمل والتعاقد (عمومي)**: مناصب شاغرة، فرص تعاقد وشراكة، حاجات خدمية،
  وتداريب — بحث وتصفية (نوع/قطاع/جهة)، بطاقات بتفاصيل وآخر أجل وعدد المناصب،
  وترشح فوري للزوار والمستخدمين؛ وتبويبات إدارة للمسيّرين (نشر الفرص ودراسة الترشيحات).
- **فضاء العضو/المتعاقد**: حقوق المنخرط حسب القانون 112.12 — بطاقة التعاونية
  والعضوية، تأكيد الحضور في الجموع المبرمجة، والتصويت على القرارات
  (موافقة/معارضة/امتناع — صوت واحد لكل عضو لكل جمع). المتعاقد يطلع على الوثائق
  المصرح بها فقط (مفتاح مشاركة جديد في سجل الوثائق).
- **الصفحات القانونية للمنصة**: مركز قانوني بأربعة وثائق مهنية — الشروط العامة،
  سياسة الخصوصية وحماية المعطيات (القانون 09.08 والمرسوم 2.09.19 وCNDP)، الإشعار
  القانوني (القانون 53.05 والقانون 2.00 وحماية المستهلك 31.08)، وسياسة ملفات
  تعريف الارتباط.
- **المساعد الألي (شاتبوت)**: عامل Cloudflare Workers AI على حساب مستقل
  (cmdp-assistant.tkchouika-cmdp.workers.dev) بنموذج GPT-OSS-120B وتعليمات صارمة:
  قائمة روابط بيضاء حصرية (لا اختلاق روابط)، نطاق محدد (المنصة والتعاونيات)،
  واعتذار صريح عند عدم اليقين — مع بديل محلي حتمي داخل الواجهة عند تعذر العامل،
  وتحديد معدل 15 طلباً/دقيقة، وخصوصية تامة (لا معطيات شخصية).
- **حسابات العرض حسب الأدوار**: superadmin / admin / president / manager / member /
  contractor — كلمة المرور cmdp2026، مع بيانات نموذجية (9 مستخدمين، 4 طلبات انخراط،
  10 فرص، 4 ترشيحات، تعاونية قيد المصادقة).
- **الرئيسية المحسّنة**: أزرار «أنشئ حسابك أو انخرط الآن» و«فرص العمل والتعاقد» في
  الهيرو والترويسة والفوتر، وتباين أفضل لمحاور الرسم البياني على الهواتف.

### أُصلح

- **روابط الفوتر المعطلة** (خلل مُبلَّغ عنه): روابط «وحدات المنصة» و«مراجع» كانت
  نصوصاً غير قابلة للنقر. أصبحت كلها روابط فعلية عاملة: توجيه داخلي للوحدات
  والوثائق القانونية، وروابط رسمية خارجية (ODCO، وزارة القطاع، الضرائب، CNSS)
  بفتح في تبويب آمن.
- إبطال استعلامات فوري بعد قرارات المصادقة والترشيحات (تحديث القوائم بدون إعادة تحميل).
- موضع زر المساعد الألي (جهة النهاية) حتى لا يغطي أزرار الشريط الجانبي أو تسجيل الخروج.

### البنية التقنية (المستجد)

- 6 نماذج Prisma جديدة + حقلان (User.roles/status، Cooperative.approvalStatus،
  Document.isShared) و14 مسار API إضافي، ومصفوفة صلاحيات مشتركة بين الواجهة والخادم.

## [1.0.0] — 2026-11-04

أول إصدار عمومي للمنصة — نسخة التأسيس.

### أُضيف

- **الصفحة الرئيسية التعريفية**: هيرو بتصميم مغربي (قوس، زليج، رسم بياني مصغر)،
  إحصائيات القطاع التعاوني المغربي (65,315 تعاونية نشيطة — ODCO 2025)، 6 مزايا،
  8 وحدات قابلة للاستكشاف، قسم الإطار القانوني مع مسار التأسيس في 6 خطوات.
- **وحدة الدخول**: مصادقة عبر SQLite (scrypt) مع وضع عرض احتياطي للنسخة الساكنة
  (بيانات العرض: `admin / cmdp2026`).
- **لوحة القيادة**: مؤشرات الأعضاء والحصص والسيولة، رسم الإيرادات/المصاريف لآخر 12 شهراً،
  توزيع التعاونيات حسب القطاع، تطور الأعضاء التراكمي، المواعيد النظامية القادمة مع
  إمكانية إنجازها، صحة الوثائق، آخر الحركات والجمعات.
- **وحدة التعاونيات**: سجل كامل (CRUD) مع بحث وتصفية، بطاقة تفاصيل، تعيين تعاونية نشطة.
- **وحدة الأعضاء**: سجل المنخرطين مع الحصص ومناصب المجلس، بحث وتصفية، جدول للشاشات
  الكبيرة وبطاقات للهواتف.
- **وحدة الجمع العام والمجلس**: خط زمني للجمعات (تأسيسي/عادي/استثنائي) مع جداول الأعمال
  والقرارات ونسب الحضور، واجتماعات المجلس وتركيبته.
- **وحدة المالية والصندوق**: نظرة عامة بالرسوم، سجل الحركات (CRUD)، تقرير مالي سنوي
  وكشف حساب **قابلان للطباعة** بترويسة وتوقيع.
- **سجل الوثائق**: أرشيف مصنف مع حساب آلي لحالة الصلاحية (سارية/قاربت/منتهية) وتنبيهات العدّ التنازلي.
- **الجهات الوصية**: دليل 9 جهات (ODCO، كتابة الدولة، DGI، CNSS، ONCA...) مع المهام
  والروابط، وسجل تفاعلات كامل (تصريحات/طلبات/مراسلات/زيارات/تدقيق).
- **مكتبة القوانين**: 10 نصوص موثقة (112.12، المرسوم 2.15.617، قرار 1369.16، 24.83 الملغى،
  الإطار 10.21، المدونة الجبائية، مبادئ ICA...) مع النقاط الأساسية والروابط الرسمية.
- **الإعدادات**: إدارة الحساب والمظهر، **ضبط عنوان الباك إند المحلي** مع اختبار اتصال،
  إعادة ضبط البيانات التجريبية.
- **الباك إند**: 21 مسار REST API مع CORS، طبقة بيانات مزدوجة (خادم/عرض تجريبي)،
  سكريبت بذر ببيانات واقعية، ونسخة ساكنة للنشر (`npm run build:static`).
- **التوثيق**: README، بروتوكول العمل المشترك بين المساعدين، WORKLOG، CHANGELOG،
  دليل النشر، منهجية القياس والمراجعة.

### البنية التقنية

- Next.js 16 (App Router) + TypeScript 5 + Tailwind CSS 4 + shadcn/ui + Prisma (SQLite)
- واجهة عربية RTL بالكامل بخطوط Cairo/Tajawal/Amiri وثيم فاتح/داكن
- نظام تصميم مغربي: درجات الطين والزعفران والزليج، نجمة الخطّام، الأقواس المغربية
